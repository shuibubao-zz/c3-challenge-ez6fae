## 怎么用这个包

### 第 1 步：发出（约 10 分钟）

打开 `反思.md` 第二部分，每条记录的【原文】块可以直接复制发到群里。顺序建议：

1. **P1 先发**（提问，最容易引发讨论）
2. 视情况发 **P2 / P5**（分享类，自带量化证据，阅读门槛低）
3. **P3** 在有人问「AI 的数字能不能用」时发出（回应类，需要对口场景）
4. **P4 最后发**（回馈，把 P1 的结论还给群）

每篇都已控制在群消息可读的长度，长证据走仓库链接或附件。

### 第 2 步：回填（每条 3 行）

收到回应后，回到该条的【后续结果】回填区填：

- 实际发出时间
- 收到的回应（摘录原文）+ 回应人
- **据此我改变了什么**（具体动作 + 落在哪个文件）

### 第 3 步：更新自评

回填完成后，更新 `AAR.md` ②（参与质量）与 ④（协作贡献）的自评分 —— 当前自评是**按未发出状态**打的，回填后可达 23–25 / 13–15。

### 第 4 步：勾选回填清单

`反思.md` 末尾有「回填清单」，逐条打勾。
